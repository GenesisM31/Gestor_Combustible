# Gestor_Combustible

Sobre el proyecto

Bolivia enfrenta una crisis de abastecimiento de diésel y gasolina, agravada por el desvío de combustible subvencionado hacia el contrabando. Este proyecto propone una plataforma que conecta estaciones de servicio, YPFB y ANH y complementa al sistema B-SISA con un módulo de alertas.
**Funcionalidades**
Registro de cada carga: vehículo, volumen y hora.
Verificación de cuota e historial antes de autorizar la venta.
Seguimiento del combustible desde la planta hasta la estación.
Alertas por cargas repetidas o volúmenes que exceden la capacidad del tanque.
